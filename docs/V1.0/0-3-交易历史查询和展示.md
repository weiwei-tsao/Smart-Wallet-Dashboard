## 交易历史查询和展示功能详解

### 1. 逻辑流程

此功能模块负责获取特定钱包地址的交易历史记录并将其呈现在用户界面上。由于区块链上的交易数据量庞大，我们不会直接从区块链节点获取，而是依赖于专门的区块链浏览器 API。

#### **步骤 1：准备 API 请求**

- **获取 API Key**: 首先，你需要到 **Etherscan** 官网注册账户，并申请一个 API Key。Etherscan API 是一个广泛使用的工具，用于查询以太坊主网和测试网的数据。
- **构建 API 请求 URL**: 使用你的钱包地址和 API Key，构造一个 API 请求 URL。Etherscan 提供了一个专门用于获取账户交易历史的 API 端点。
  - **API 端点**: `https://api.etherscan.io/api`
  - **查询参数**:
    - `module=account`：指定模块为账户。
    - `action=txlist`：指定操作为获取交易列表。
    - `address=<wallet_address>`：替换为当前连接的钱包地址。
    - `sort=desc`：按时间倒序排列，以显示最新交易。
    - `apikey=<your_api_key>`：替换为你的 Etherscan API Key。

#### **步骤 2：发起网络请求**

- **时机**: 在成功获取钱包地址后立即进行。
- **实现**: 使用 JavaScript 的内置 `fetch` API 或流行的库如 `axios` 向构建好的 URL 发起 GET 请求。

#### **步骤 3：处理 API 响应数据**

- **解析响应**: API 返回的是一个 JSON 对象。你需要解析该对象，找到包含交易数据的 `result` 数组。
- **数据提取**: 遍历 `result` 数组，从每个交易对象中提取关键信息：
  - `hash`：交易哈希，唯一标识一笔交易。
  - `from` 和 `to`：交易的发送方和接收方地址。
  - `value`：交易金额，单位为 wei。
  - `timeStamp`：交易发生的时间戳，需要转换为可读的日期格式。
  - `isError`：表示交易是否失败，`"0"` 表示成功，`"1"` 表示失败。
- **数据转换**: 将 `value` 从 wei 转换为 ETH，使用 **Ethers.js** 的 `ethers.utils.formatEther()` 函数。

#### **步骤 4：UI 展示**

- **加载状态**: 在请求 API 期间，显示一个加载指示器，告知用户正在获取数据。
- **列表展示**: 使用列表或表格的形式，将提取和转换后的交易数据显示出来。每一行或每一项代表一笔交易，清晰地展示哈希、收发地址、金额、时间和状态。
- **无交易记录**: 如果 `result` 数组为空，显示“该地址暂无交易记录”等友好提示。

### 2. 页面接口

此功能主要依赖于外部的 **Etherscan API**。

- **Etherscan API (txlist)**
  - **功能**: 获取特定钱包地址的交易历史列表。
  - **URL 示例**: `https://api.etherscan.io/api?module=account&action=txlist&address=<wallet_address>&sort=desc&apikey=<your_api_key>`
  - **返回格式**: 一个包含交易对象数组的 JSON 响应。
