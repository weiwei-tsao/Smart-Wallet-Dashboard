## 钱包基本信息展示功能详解

### 1. 逻辑流程

这个功能模块负责在用户成功连接钱包后，获取并展示其核心资产信息。

#### **步骤 1：获取钱包地址**

- **时机**: 在**“连接 MetaMask 钱包”**功能成功执行后立即触发。
- **实现**: 通过 **Ethers.js** 的 `provider.getSigner()` 方法，你可以获得一个 `Signer` 对象。然后，调用 `signer.getAddress()` 即可获取当前连接的钱包地址。

#### **步骤 2：获取主网币余额**

- **时机**: 在获取到钱包地址后，立即进行。
- **实现**: 调用 **Ethers.js** 的 `provider.getBalance(address)` 方法。
- **数据格式**: 这个方法会返回一个 `BigNumber` 对象，代表余额，单位是 `wei`（以太坊最小单位）。你需要使用 **Ethers.js** 的 `ethers.utils.formatEther()` 工具函数将其转换为可读的 **ETH** 单位。
- **UI 展示**: 将格式化后的余额显示在仪表盘上。

#### **步骤 3：获取当前网络信息**

- **时机**: 在获取钱包地址后，立即进行。
- **实现**: 调用 **Ethers.js** 的 `provider.getNetwork()` 方法。这个方法会返回一个包含网络名称（`name`）和链 ID（`chainId`）的对象。
- **UI 展示**: 将网络名称（如“Ethereum Mainnet”）显示在界面上。

#### **步骤 4：处理数据加载状态**

- **加载中**: 在获取所有信息（地址、余额、网络）的过程中，界面可以显示一个加载指示器（如“加载中...”）。
- **加载完成**: 所有数据都成功获取后，移除加载指示器，并显示所有信息。
- **错误处理**: 如果在任何步骤中发生错误（例如，网络请求失败），捕获异常并在界面上显示友好的错误信息，如“无法获取钱包信息”。

### 2. 页面接口

这些是你的前端应用需要调用的、用于获取信息的**Ethers.js**核心方法。

- **`provider.getSigner()`**

  - **功能**: 获取与当前钱包地址关联的 `Signer` 对象。

- **`signer.getAddress()`**

  - **功能**: 从 `Signer` 对象中获取钱包地址字符串。

- **`provider.getBalance(address)`**

  - **功能**: 获取指定地址的主网币余额，返回一个 `BigNumber` 对象（单位为 wei）。

- **`ethers.utils.formatEther(balance)`**

  - **功能**: 将 `BigNumber` 格式的 wei 余额转换为以太坊单位的浮点数字符串。

- **`provider.getNetwork()`**
  - **功能**: 获取当前连接的网络信息（名称、链 ID）。
