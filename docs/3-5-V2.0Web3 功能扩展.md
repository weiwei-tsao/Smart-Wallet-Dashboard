## 4\. Web3 功能扩展

这部分是项目区别于普通 Web 应用的关键所在。它要求你展示对 Web3 协议的理解和实际操作能力。

### 4.1 增强 Ethers.js 合约交互

我们将使用 **Ethers.js** 这个强大的库来与以太坊智能合约进行交互。

- **准备工作：ABI 与合约地址**

  - 为了与 ERC-20 合约交互，你需要该合约的 **ABI (Application Binary Interface)**。ERC-20 是一个标准，所以你可以找到通用的 ERC-20 ABI。
  - 你需要一个具体的 ERC-20 **合约地址**作为演示。例如，你可以选择 USDT、DAI 或你自己的测试合约地址。

- **实现功能：读取合约元信息**

  - 在前端，创建一个新的组件或区块，例如 `ContractInfo.js`。
  - 使用 `Ethers.js` 的 `Contract` 类来创建一个合约实例。你需要传入三个参数：`合约地址`、`合约 ABI` 和一个 `Provider`。这个 `Provider` 负责连接到区块链。

    ```javascript
    import { ethers } from 'ethers';

    // 你的代码需要获取一个 Provider
    // 例如，使用 Ethers.js 的默认 Provider
    const provider = ethers.getDefaultProvider();

    const contractAddress = '0x...'; // ERC-20 合约地址
    const contractABI = [...] // ERC-20 的 ABI

    // 创建合约实例
    const contract = new ethers.Contract(contractAddress, contractABI, provider);

    // 调用合约的只读方法
    async function fetchContractInfo() {
      try {
        const totalSupply = await contract.totalSupply();
        const decimals = await contract.decimals();
        // ... 处理并展示数据
      } catch (error) {
        console.error("Error fetching contract info:", error);
      }
    }
    ```

  - 在 Dashboard 页面，展示这些合约元信息，如代币的 **总供应量（totalSupply）** 和 **精度（decimals）**。为了更好的用户体验，你可以将 `totalSupply` 格式化为更易读的单位。

### 4.2 选择测试网部署或交互

为了项目的完整性，我们需要在真实的区块链网络上进行演示。

- **选择测试网**：**Sepolia** 是目前最推荐的以太坊测试网，因为它被以太坊基金会长期支持。Goerli 也仍然可用，但未来会逐渐被弃用。
- **获取测试币**：你需要从一个 Sepolia 水龙头（faucet）获取一些测试 ETH，以便进行交易和测试。
- **部署与交互**：
  - **部署**：如果你有自己的智能合约，可以尝试将其部署到 Sepolia 测试网。
  - **只读交互**：更简单也更安全的方式是，直接在 Dashboard 上展示 **只读** 的功能。例如，一个“钱包余额 Demo”模块，它会读取你在 Sepolia 上的钱包余额，并展示最近的几笔交易。
  - **最小交易功能**：创建一个按钮，展示如何构造一个最小的 `transfer` 或 `mint` 交易。在实际项目中，你可能会使用类似 **MetaMask** 的浏览器钱包来签名并发送交易。在你的演示中，你可以只展示代码逻辑，而无需实际执行，以避免风险。

### 4.3 前端增加 “合约交互 Demo” 区块

- **设计一个新区块**：在 Dashboard 页面上，创建一个独立的、标题为 "**合约交互演示**" 的区块。
- **功能实现**：
  - 提供一个输入框，让用户可以输入任意一个 ERC-20 合约地址。
  - 当用户点击“查询”按钮时，调用你用 Ethers.js 编写的函数，去区块链上读取该合约的 `totalSupply()` 和 `decimals()`。
  - 将查询结果清晰地展示在页面上。
  - 这个功能极大地提升了项目的 Web3 亮点，因为它展示了项目不仅能读取钱包信息，还能直接与智能合约进行交互。
