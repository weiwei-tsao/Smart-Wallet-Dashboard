基于 React + Vite 的 Web3 钱包项目需求：

1.  连接 MetaMask 钱包
    
      - 实现连接按钮，并处理连接成功、失败及MetaMask未安装的情况。

2.  显示钱包基本信息
    
      - 显示钱包地址（可截断显示）。
      - 显示当前网络上的主网币余额（如 ETH）。
      - 显示当前连接的网络名称。

3.  交易历史查询和展示
    
      - 使用如 Etherscan API 获取交易历史。
      - 以列表形式展示交易记录，包括交易哈希、收发地址、金额和时间。

4.  代币余额显示
    
      - 使用如 Etherscan API 获取用户地址上的所有 ERC-20 代币余额。
      - 展示代币名称、余额和合约地址。
