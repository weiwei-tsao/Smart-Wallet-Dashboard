# Smart-Wallet-Dashboard v2.0 功能清单

## 1. 前端（Next.js + React）

- 将现有 React + Vite 迁移到 Next.js
- 新增 /address/[id] 动态路由页面
- 实现 SSR/ISR 渲染钱包余额与最近交易列表
- 在 README 中说明 SSR vs. ISR 的对比及适用场景
- 保留 Redux Toolkit、Tailwind、Apollo Client 结构，保持组件可复用

## 2. 后端（Node/Express BFF）

- 新建一个 Node/Express BFF 服务，作为前端与链上数据 API 的中间层

- 提供 REST API 路由：

  - GET /api/tx?address= → 调用 Etherscan API，返回交易数据（带缓存）

  - GET /api/tokens?address= → 返回 ERC-20 Token 列表（带缓存）

- 集成 Redis 缓存：

  - 交易与 Token 数据缓存 30–60 秒，减少 API 请求次数

- 使用 PostgreSQL 存储用户偏好：

  - 收藏地址

  - 自定义标签（alias）

- 提供 POST /api/favorites、GET /api/favorites 简单 CRUD 接口

## 3. 基础设施（Docker & CI/CD）

- 使用 Docker & Docker Compose 管理开发环境：

  - web → Next.js 前端
  - bff → Node/Express 后端
  - redis → 缓存层
  - postgres → 数据存储

- 本地一键启动四容器，方便团队与面试官快速复现

- 配置 GitHub Actions CI/CD：

  - 步骤：Install → Lint → Type-check → Unit test → Build

  - 自动触发：PR / push main 分支

  - 可选：自动部署到 Vercel / Render

## 4. Web3 功能扩展

- 增强 Ethers.js 合约交互：

  - 读取 ERC-20 合约的 totalSupply() 和 decimals()

  - 在 Dashboard 展示合约元信息

- 选择一个测试网（Goerli / Sepolia）部署或交互：

  - Demo 功能：读取余额、执行最小 transfer/mint 操作（只读即可）

- 前端增加 “合约交互 Demo” 区块，提升 Web3 亮点
