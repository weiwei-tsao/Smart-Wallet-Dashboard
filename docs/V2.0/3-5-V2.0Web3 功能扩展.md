## 4\. Web3 功能扩展

这部分是项目区别于普通 Web 应用的关键所在。它要求你展示对 Web3 协议的理解和实际操作能力。

### 4.1 增强 Ethers.js 合约交互

我们将使用 **Ethers.js** 这个强大的库来与以太坊智能合约进行交互。

- **准备工作：ABI 与合约地址**

  - 为了与 ERC-20 合约交互，你需要该合约的 **ABI (Application Binary Interface)**。ERC-20 是一个标准，所以你可以找到通用的 ERC-20 ABI。
  - 你需要一个具体的 ERC-20 **合约地址**作为演示。例如，你可以选择 USDT、DAI 或你自己的测试合约地址。

- **实现功能：读取合约元信息**

  - 在前端，创建一个新的组件或区块，例如 `ContractInfo.tsx`。
  - 使用 `Ethers.js` 的 `Contract` 类来创建一个合约实例。你需要传入三个参数：`合约地址`、`合约 ABI` 和一个 `Provider`。这个 `Provider` 负责连接到区块链。

    ```typescript
    import { ethers } from 'ethers';

    // 你的代码需要获取一个 Provider
    // 例如，使用 Ethers.js 的默认 Provider
    const provider = ethers.getDefaultProvider();

    const contractAddress = '0x...'; // ERC-20 合约地址
    const contractABI = [...] // ERC-20 的 ABI

    // 创建合约实例
    const contract = new ethers.Contract(contractAddress, contractABI, provider);

    // 调用合约的只读方法
    async function fetchContractInfo() {
      try {
        const totalSupply = await contract.totalSupply();
        const decimals = await contract.decimals();
        // ... 处理并展示数据
      } catch (error) {
        console.error("Error fetching contract info:", error);
      }
    }
    ```

  - 在 Dashboard 页面，展示这些合约元信息，如代币的 **总供应量（totalSupply）** 和 **精度（decimals）**。为了更好的用户体验，你可以将 `totalSupply` 格式化为更易读的单位。

### 4.2 Etherscan V2 API 集成

通过集成 **Etherscan V2 API**，我们可以获取更丰富的链上数据，支持多链查询。

- **V2 API 优势**：

  - 统一的 API 端点支持多链查询
  - 更好的性能和稳定性
  - 支持更多区块链网络（Ethereum, Polygon, BSC, Arbitrum, Optimism 等）
  - 改进的速率限制和错误处理

- **多链支持实现**：

  ```typescript
  // 支持的区块链网络配置
  const SUPPORTED_CHAINS = {
    1: { name: 'Ethereum Mainnet', rpc: 'https://eth.llamarpc.com' },
    137: { name: 'Polygon', rpc: 'https://polygon.llamarpc.com' },
    56: { name: 'BSC', rpc: 'https://bsc.llamarpc.com' },
    42161: { name: 'Arbitrum', rpc: 'https://arbitrum.llamarpc.com' },
    10: { name: 'Optimism', rpc: 'https://optimism.llamarpc.com' },
  };

  // Etherscan V2 API 调用
  const fetchTransactionHistory = async (
    address: string,
    chainId: number = 1
  ) => {
    const response = await fetch(
      `https://api.etherscan.io/v2/api?chainid=${chainId}&module=account&action=txlist&address=${address}&apikey=${API_KEY}`
    );
    return response.json();
  };
  ```

- **数据聚合与缓存**：
  - 通过 BFF 服务聚合多个数据源
  - 使用 Redis 缓存减少 API 调用
  - 实现数据标准化和格式化

### 4.3 多链钱包支持

通过集成多个区块链网络，提供更全面的 Web3 体验。

- **支持的网络**：

  - **Ethereum Mainnet** (Chain ID: 1) - 主要的以太坊网络
  - **Polygon** (Chain ID: 137) - 低费用的以太坊侧链
  - **BSC** (Chain ID: 56) - 币安智能链
  - **Arbitrum** (Chain ID: 42161) - 以太坊 Layer 2 解决方案
  - **Optimism** (Chain ID: 10) - 另一个以太坊 Layer 2 解决方案

- **网络切换功能**：
  ```typescript
  // 网络切换组件
  const NetworkSelector = () => {
    const [selectedChain, setSelectedChain] = useState(1);

    const switchNetwork = async (chainId: number) => {
      try {
        await window.ethereum.request({
          method: 'wallet_switchEthereumChain',
          params: [{ chainId: `0x${chainId.toString(16)}` }],
        });
        setSelectedChain(chainId);
      } catch (error) {
        console.error('Failed to switch network:', error);
      }
    };

    return (
      <select
        value={selectedChain}
        onChange={(e) => switchNetwork(Number(e.target.value))}
      >
        {Object.entries(SUPPORTED_CHAINS).map(([chainId, config]) => (
          <option key={chainId} value={chainId}>
            {config.name}
          </option>
        ))}
      </select>
    );
  };
  ```
