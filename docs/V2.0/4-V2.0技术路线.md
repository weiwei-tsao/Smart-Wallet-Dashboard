## 📋 V2.0 项目调整分析

基于 V2.0 功能文档，我们需要对现有项目进行重大架构调整。以下是详细的分析：

### 🔄 **1. 前端架构调整（React + Vite → Next.js）**

#### **当前状态：**

- 使用 React + Vite 构建
- 单页面应用（SPA）
- 客户端渲染（CSR）

#### **需要调整：**

- **迁移到 Next.js**：从 Vite 迁移到 Next.js 框架
- **新增动态路由**：创建 `/pages/address/[id].js` 动态路由
- **实现 SSR/ISR**：使用 `getServerSideProps` 和 `getStaticProps`
- **保持现有技术栈**：Redux Toolkit、Tailwind CSS、Ethers.js

#### **目录结构调整：**

```
当前结构：
src/
├── pages/Dashboard.tsx
├── components/
├── hooks/
└── ...

V2.0 结构：
pages/
├── index.js (首页)
├── address/
│   └── [id].js (动态路由)
├── _app.js (全局配置)
└── _document.js (HTML 结构)
src/
├── components/ (保持)
├── hooks/ (保持)
├── services/ (保持)
└── ...
```

## 💪 **关键决策点**

1. **保持现有组件**：大部分 React 组件可以复用
2. **渐进式迁移**：可以分阶段实施，先迁移前端再添加后端
3. **技术栈选择**：保持 Redux Toolkit 和 Tailwind，添加 Next.js
4. **数据库设计**：简单的 favorites 表，包含 id、address、alias 字段

这个调整计划将把现有的简单前端项目升级为一个完整的全栈 Web3 应用，具备 SSR、缓存、数据库、容器化等企业级特性。
