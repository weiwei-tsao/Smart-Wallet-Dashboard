## 代币余额显示功能详解

### 1. 逻辑流程

此功能模块旨在查询并展示用户钱包中持有的所有 **ERC-20** 代币及其余额。同样，我们将依赖 **Etherscan API**。

#### **步骤 1：准备 API 请求**

- **构建 API 请求 URL**: 使用你的钱包地址和 API Key，构造一个 API 请求 URL。Etherscan 提供了专门用于获取代币余额的 API。
  - **API 端点**: `https://api.etherscan.io/api`
  - **查询参数**:
    - `module=account`：指定模块为账户。
    - `action=tokenlist`：指定操作为获取代币列表。
    - `address=<wallet_address>`：替换为当前连接的钱包地址。
    - `apikey=<your_api_key>`：替换为你的 Etherscan API Key。

#### **步骤 2：发起网络请求**

- **时机**: 在成功获取钱包地址后，与交易历史查询并行或串行发起。
- **实现**: 使用 `fetch` 或 `axios` 向构建好的 URL 发起 GET 请求。

#### **步骤 3：处理 API 响应数据**

- **解析响应**: API 返回一个 JSON 对象，其 `result` 数组包含了所有代币的余额信息。
- **数据提取**: 遍历 `result` 数组，从每个代币对象中提取关键信息：
  - `tokenName`：代币的全称，如“Tether USD”。
  - `tokenSymbol`：代币的符号，如“USDT”。
  - `balance`：代币余额，通常是一个 `String` 类型的 `BigNumber`。
  - `contractAddress`：代币的合约地址。
  - `tokenDecimal`：代币的精度，用于将余额转换为可读格式。
- **数据转换**:
  - 由于每个代币的精度不同，你需要使用 **Ethers.js** 的 `ethers.utils.formatUnits()` 工具函数，并传入 `balance` 和 `tokenDecimal` 来正确格式化余额。例如，USDT 的精度是 6，而有些代币可能是 18。

#### **步骤 4：UI 展示**

- **加载状态**: 在请求 API 期间，显示加载指示器。
- **列表展示**: 以列表或卡片的形式展示代币信息，包括图标、名称、符号和格式化后的余额。
- **无代币**: 如果 `result` 数组为空，显示“该地址暂无代币”的提示。

### 2. 页面接口

此功能主要依赖于外部的 **Etherscan API**。

- **Etherscan API (tokenlist)**
  - **功能**: 获取特定钱包地址的 **ERC-20** 代币列表和余额。
  - **URL 示例**: `https://api.etherscan.io/api?module=account&action=tokenlist&address=<wallet_address>&apikey=<your_api_key>`
  - **返回格式**: 一个包含代币对象数组的 JSON 响应。
